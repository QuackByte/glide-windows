# 更新日志

这里记录了 Glide for Windows 每个版本的新变化。Glide 会在更新后显示一次新增的条目，GitHub 上每个版本的说明也来自这里，所以请以 Glide 用户的角度来写。本文件是 CHANGELOG.md 的译文，CHANGELOG.md 才是原文。每次发布前，请在下一个版本下为每项值得了解的改动添加一条记录。

## 0.9.3 — 2026-10-19

### 新增

- **平铺布局。** 按 Win+Ctrl+T 可将当前工作区在滚动条带和平铺布局之间切换。在平铺布局中，所有列共享屏幕，无需滚动即可全部显示。每个工作区都会保留自己的布局，即使重启 Glide 也不例外。循环切换列宽（Win+Ctrl+R）可让某一列占据更大或更小的份额，拖动其边缘可调整大小，而 Win+Ctrl+F 仍可让它保持全宽，直到你再次按下。
- **选择新工作区的初始布局**，位于“设置 › 常规 › 布局”：滚动（和以前一样）或平铺。已用 Win+Ctrl+T 切换过的工作区会保留各自的布局。

## 0.9.2 — 2026-10-16

### 新增

- **“新功能”也支持你的语言了。** Glide 在更新后显示的说明，以及“新功能”中的内容，现在与 Glide 的其余部分使用相同的语言。

## 0.9.1 — 2026-10-16

### 新增

- **Glide 支持你的语言。** 除英语和西班牙语外，Glide 现在还有法语、德语、日语、简体中文、韩语和巴西葡萄牙语版本，安装程序也一样。它会跟随 Windows 的显示语言，你也可以在“设置 › 常规 › 语言”中选择。

## 0.9.0 — 2026-10-15

### 新增

- **拖动窗口时预览落点。** 拖动窗口时，会以焦点环的颜色显示一个轮廓，指出它将加入哪一列（包括标签页栏）。拖到另一台显示器上时，会用一条横杠表示它将插入该显示器哪两列之间。没有高亮则表示窗口会弹回原位。
- **更丰富的通知区域菜单。** 它会列出正在使用的工作区及各自的窗口数量，选择其中一个即可前往。**快捷键** 下列出了每个操作及其快捷键，可直接从菜单中执行。当“接管 Windows 快捷键”关闭时，菜单还会列出 Windows 保留的快捷键。
- **所有快捷键集中在一页。** 按 Win+Ctrl+/（美式键盘上带 ? 的那个键）即可查看全部快捷键；再按一次或按 Esc 即可关闭。通知区域菜单的“快捷键”下也有此项。
- **报告问题…**，位于通知区域菜单和“设置 › 常规”中。Glide 会把日志和设置（已去除窗口标题）打包成 zip，并在 GitHub 上为你打开一个新的 issue，供你描述发生了什么并附上该 zip。不会自动发送任何内容。
- **Glide 会说西班牙语。** 当 Windows 使用西班牙语时，Glide 也会使用西班牙语，安装程序也一样。“新功能”仍为英语。

### 修复

- **全屏就保持全屏。** 视频、游戏，或在浏览器中按 F11，不会再被拉回它所在的列。Glide 不再干预：会在其上隐藏焦点环、调暗效果和标签页栏，并让水平滚轮和触摸板轻扫直接作用于它。
- 切换到 Windows 的另一个虚拟桌面再切换回来后，各列的顺序保持不变。
- 关闭窗口后，焦点不再从 Glide 自己的窗口（例如“新功能”或“设置”）上被抢走。

## 0.8.1 — 2026-10-14

### 修复

- 点击“新功能”窗口中的 **继续** 会导致 Glide 退出。现在关闭窗口后，Glide 会继续运行。
- 通知区域图标会显示所有正在使用的工作区：九个工作区组成 3×3 的网格，正在使用的亮起，当前的最亮。只有一个工作区在使用时，仍像以前一样显示其编号。

## 0.8.0 — 2026-10-14

### 新增

- **调暗未聚焦的窗口。** 同一显示器上，位于聚焦窗口后面的窗口会变暗，让聚焦的窗口更突出。默认关闭；可在“设置 › 外观”中开启并调节暗度。
- **列出所有正在使用的工作区。** 通知区域图标的提示和菜单会显示所有有窗口的工作区。图标仍显示当前的工作区。
- **切换时显示在屏幕上的工作区编号** 可以关闭，位置在“设置 › 外观”。
- **自动安装更新。** 默认关闭。在“设置 › 更新”中开启后，Glide 一发现新版本就会安装，然后重新启动。

### 变更

- 发布的版本尚未进行代码签名，因此 Windows SmartScreen 可能会在你首次运行 Glide 时发出警告：请选择 **更多信息 › 仍要运行**。
- 安装程序中的隐私政策不再链接到代码签名政策。

## 0.7.0 — 2026-10-14

### 新增

- **Glide 会自动保持最新。** 它每天检查两次是否有新版本，并通过通知区域图标提示你。每个下载在安装前都会经过验证，Glide 会先把窗口放回原位，更新后再重新启动。可在“设置 › 更新”中关闭，也可以在安装时关闭。
- **新功能。** 更新后，Glide 会显示有哪些变化，就像现在这样。之后可在通知区域菜单中再次查看。
- **应用回到你常用的位置。** Glide 会记住每个应用所在的显示器、工作区、列宽和在条带上的位置。重新打开的应用，其窗口会在那里打开；重启后，你已打开的窗口也会按相同方式排列。可在“设置 › 常规”中关闭，或忘记所有位置。
- **Glide 是开源的**，采用 MIT 许可证：[github.com/QuackByte/glide-windows](https://github.com/QuackByte/glide-windows)。

### 变更

- 安装程序现在会显示 Glide 的隐私政策，并让你选择 Glide 是否检查更新。

## 0.6.0 — 2026-10-14

### 新增

- **应用图标** 现在显示在概览和标签页栏的窗口标题旁。
- **概览可以滚动。** 当条带太长、屏幕放不下时，概览会滚动，而不是把窗口缩小到看不清。滚轮会滚动指针所在的那一行。

### 修复

- 标签页栏现在会随所在列一起滑动，而不是跑到列的前面。
- 堆叠或取消堆叠后，焦点环有时会出现在窗口原来的位置。现在它会跟随窗口。

## 0.5.0 — 2026-10-14

### 新增

- **多显示器**：每台显示器都有自己的条带和九个工作区。Win+Alt+←/→ 在显示器之间移动焦点；Win+Alt+Shift+←/→ 把聚焦的列送过去。
- **拖放**：把窗口放到标签页栏上，即可加入标签页；放到另一个窗口上，即可堆叠到那里；放到另一台显示器上，即可移到那台显示器。
- **适用于每个应用的焦点环**，包括 Electron 应用，粗细可以设置。
- **触摸板三指轻扫** 可沿条带滑动。
- 通知区域菜单中新增“登录时启动 Glide”。
